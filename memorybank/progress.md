## Current Blockers

- runtime LOD selection is still distance-band based inside `VegetationRenderWorld`; screen-error/hysteresis remains future production hardening
- externalized async near-detail payload providers for disk/Addressables-backed pages are still pending; current residency is budgeted inside the render world over compiled page assets
- dense-forest, mobile, VR, and large shadow validation are still pending on the compiled render-world path
- dense-forest performance regression source fix is in code: HLOD now uses one baked impostor instance per tree, packet selection uses lookup ranges, depth/color camera preparation can be reused, near-detail admission request-loads nearest camera cells at cell granularity before degrading through cheaper tiers to impostor, and `VegetationRenderWorld.Prepare` now uses persistent native upload staging plus sparse active-group args updates to avoid managed staging churn. Runtime near-cell priority and LOD tier selection use distance to compiled cell bounds instead of cell center, so elongated cells do not demote camera-adjacent trees. Main-light shadow cascades now prepare as one batched frustum set, reuse one static packet payload across cascade draws, skip cascade/group submissions with no selected shadow packets, and use page/cell cascade masks so four cascades do not independently rescan broad-phase cells. The vegetation shadow pass now appends into URP's main shadow atlas as a raster `ReadWrite` depth attachment instead of using unsafe `SetRenderTarget`, fixing the DirectX shadow/color target-state failure. The package shaders now gate `_VegetationInstanceData` behind `_VOXGEOFOL_INDIRECT_RENDERING`, which only `VegetationRenderWorld` enables around indirect draws, so regular container/preview MeshRenderer paths do not request an unbound SRV on DirectX. Grouped indirect draws now keep `startInstance` zero and bind `_VegetationInstanceDataBaseOffset` per group, fixing the DirectX path where canopy draws could read trunk payload records with `packedLeafTint = 0` and render black. Wind metadata compilation now uses owning tree bounds for phase and anchor height across branch/canopy/HLOD packets, so branch packets inherit trunk sway at the same world height instead of anchoring to their own horizontal packet bounds. Branch and canopy packets now keep full trunk-following bend weight, and the runtime shader no longer adds compiled flutter metadata to shared wind-direction displacement because that was the source of attached branch tops swaying with a larger envelope than the trunk. Canopy forward/depth/shadow passes now use branch flutter metadata only as small local vertex flutter over the trunk-following position, giving leaves independent motion without moving the attached branch packet envelope; leaf flutter strength, frequency multiplier, spatial scale, and secondary strength are runtime renderer-feature settings. Shader trunk-following displacement now uses one compiled tree phase plus global time, so attached branches do not run at a different time frequency from the trunk. `EnableDepthPass` can disable the dedicated vegetation depth pass when the active URP stack can rely on color-pass depth writes. `Prepare` now has submarkers for graph, broad phase, selection, upload layout, instance copy, args, and `SetData`, plus render group counters. `VegetationRendererFeature` now adds URP runtime markers around pass enqueue, render-graph record, execute, draw prepare/submit, and shadow validate/extract/prepare/submit/restore, and it reuses static RenderGraph render delegates instead of recreating render-function delegates during pass recording. DirectX indirect-args buffer creation now uses `GraphicsBuffer.Target.IndirectArguments` without `Raw`. If profiler still reports a small allocation per actual prepare, the remaining suspect is Unity's `GraphicsBuffer.SetData` upload path because this Unity API surface does not expose `GraphicsBuffer.BeginWrite`/`EndWrite`. Existing generated compiled page assets must still be regenerated after compiler changes.
- Game View/build vegetation shadows no longer rely on URP's post-shadow game camera matrix state. The shadow atlas append pass explicitly binds each cascade view/projection shader global set for indirect caster draws using GPU-adjusted projection globals, then restores camera matrices afterward. This fixes the failure mode where vegetation shadows drifted or rotated with camera motion while avoiding the raw-projection inversion failure.
